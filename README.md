# TP PHP — Gestion des étudiants

Application web PHP de gestion des étudiants avec connexion, recherche, tri,
ajout, modification, suppression et photos de profil.

## Lancement

Depuis la racine du dépôt, lancez le serveur PHP intégré :

```powershell
php -S 127.0.0.1:8000 -t .\gestion_etudiants
```

Ouvrez ensuite <http://127.0.0.1:8000>.

Compte de démonstration : `admin` / `admin123`.

Les étudiants sont enregistrés dans `gestion_etudiants/data/etudiants.txt`.
Les photos sont conservées dans `gestion_etudiants/uploads/`.

> Le compte fourni est uniquement destiné à la démonstration pédagogique.
> Remplacez-le avant toute mise en ligne réelle.
